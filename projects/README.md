# Project Index

Use this index to keep schematic folders discoverable as the repository grows.

## Project Folder Pattern

Create one folder per hardware project:

```text
projects/<project-name>/
  README.md
  parts-list.md
  wiring-notes.md
  exports/
```

## Suggested Project README Fields

- Purpose: what the circuit or board is meant to do.
- Status: idea, breadboard, tested, revised, archived.
- Controller or board: Arduino, ESP32, Raspberry Pi, custom PCB, or other.
- Power requirements: voltage, current estimate, battery or bench supply notes.
- Safety notes: heat, mains voltage, batteries, motors, or other hazards.
- Files: links to schematic exports, source files, photos, and parts lists.
